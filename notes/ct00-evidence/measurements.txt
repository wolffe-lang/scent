Measured rules (GNU, not ferp, decides):
- Program names: error diagnostics use argv[0] verbatim. With PATH grep,
  /work/bin/grep, ./grep, and PATH hound, diagnostic prefixes are those
  exact strings. Usage/Try use basename (grep or hound). R-ct00-3 keeps
  one fixed grep prefix pending wolf-lang#899; no os_exe substitution.
- Different explicit -G/-E/-F/-P syntax choices conflict, status 2; the
  same choice repeated works. cli-10..13, R-ct00-4 (contract corrected).
- POSIXLY_CORRECT presence, including the empty value, disables option
  permutation. cli-posix and cli-posix-empty.
- A trailing newline in an explicit -e introduces an empty alternative;
  a trailing newline in -f terminates its last pattern. patterns-01,
  patterns-02, no-pattern-invert. Pattern-file CR is preserved, not
  trimmed: crlf-patterns. Empty pattern files supply no patterns.
- C-locale binary mode is triggered by observed NUL, not bytes >=128.
  Default binary output is stderr `grep: NAME: binary file matches`;
  -a preserves bytes; -I suppresses the unprocessed portion. Counting
  under default binary mode uses observed NUL as a delimiter. binary-*.
- First regular-file read boundary measured at 96 KiB. A NUL at 98303
  suppresses a first x line, at 98304 allows the earlier x line. After a
  later NUL, -I returns 1 even when that x line was printed. late-nul-*.
  Pipe delivery is not fixed: the GNU manual explicitly makes the binary
  heuristic dependent on buffering/hardware; the independent probe log
  includes 64 KiB and 96 KiB pipe/regular-file witnesses.
- -U does not change CRLF on POSIX. binary-*-5 and read cases preserve CR.
- -w retries a shorter pattern at the same start when a longer word
  candidate fails: a-/a over a-b selects a, independent of order; word-0
  and word-1. KMP retains failure links to try overlapping later starts.
- -o prints nonempty spans only. Empty alternatives still select lines.
  empty-and-miss-linear is a 1 MiB no-hit nonempty alternative beside an
  empty alternative, guarding against quadratic repeated empty spans.
- GNU 3.12 gives no warning for -o with context despite the manual's
  warning sentence. Context separators still appear; inverted -o emits
  no selected text but can emit original-matching context spans.
  context-09/10 and edge-cli-13..15.
- -T omits its tab for an empty output line; numeric prefix widths are
  based on regular-file size, or 19 for a pipe. text-136 and multi-09.
- -m restores regular stdin immediately after the last selected physical
  line, ignoring read-ahead and trailing context; an unterminated final
  line has no synthesized byte in that offset. stdin-position-*,
  stdin-no-final-newline-*, stdin-offset-* compare the remaining bytes.
- Input-is-output is an error for normal/-o output, suppressed by -s,
  but is not checked for -c/-l/-L/-q; same-input-output-0..7.
- Missing files, directories, unreadable files (non-root), closed/full
  stdout, FIFO input and a live --line-buffered line before EOF all have
  dedicated cases. No unreadable/FIFO local case runs on a host process
  outside the container.

ct02 handoff: terminator-bearing patterns (R-ct00-5)
--------------------------------------------------
The initial splitting interpretation was WRONG and removed. GNU permits
matches containing the active terminator. A match's touched records are
printed once as one output unit. Pattern file x NUL y LF under -Fz over
`a NUL x NUL y NUL b NUL x NUL y NUL z NUL` prints two x/y units; -c is 2.
Pattern x NUL also includes the following record in normal output; -o
prints x NUL followed by the output NUL. Pattern NUL x starts in the
previous record and includes the next x record. A match ending just after
NUL touches the following record for normal output. These are not ordinary
OR alternatives and cannot be expressed by delimiter-excluding windows.

Observed numbering is an additional ct02 obligation: normal -n counts each
multirecord selected unit as one unit, while inverted -vn uses physical
record positions for the remaining records. For the x/y witness above,
normal -n prefixes are 2 and 4; inverted remaining records are 1,4,7.
The cases, not this prose, decide all combinations.

216 cross-* cases cover F/G/E through -f, NUL in the middle/end/start,
lone NUL, three records, and a match across the 98304-byte chunk boundary;
for each, plain/-c/-o/-b/-n/-v/-m1/-x/-w/-C1n/-onb/-vc are measured under
GNU. patterns-07 and nul-pattern-z are explicitly moved into this same
218-case terminator-pattern column by R-ct00-5, not left as disagreements.
Scent refuses them by name, exit 2. ct02 builds the adapter once for all
three syntaxes, retaining the normal reader for patterns without the
terminator. The matcher interface and ownership are in docs/MAP.md.
