across /usr/share, including filters and byte-exact colour. This is the
PAX lane's work, not a deployment claim by ct03. Use an isolated branch
and the lane's assigned container/core lock; follow wolf/sprints/RULES.md.
Never build PAX binaries against kasumi's host glibc.

2. Add a typed PAX session that uses /bin/grep -r over /usr/share; preserve

   command-line directory symlink and a walked symlink (-r versus -R).
3. Exercise --include/--exclude order, --exclude-from bytes and
   --exclude-dir, -d skip and -D skip. Include binary-in-tree and the
   output-file-in-tree identity guard when the OS surface supports them.
4. Compare --color=always SGR bytes with the record GNU fixture: default,
   custom se/ms/mt, ne, prefixes, -o and a context separator. Auto colour

   normalization. C locale is the target; keep M3 refusal visible.
5. Rebuild the dev ISO and run the typed session through its existing
   e2e gate. Add strict checks: compile exit 2 is a failure, every SKIP
   printed and counted, no success from an unexecuted grep.
